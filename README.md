# progressions

유튜브 쇼츠 영상 화면에 박힌 코드 진행을 읽어 데이터로 모읍니다.

대상은 Musician Paradise 채널의 쇼츠 1479개입니다. 영상마다 건반 위에
코드 이름이 떠 있고, 그 글자를 읽어 **무슨 코드가 언제 몇 초 동안**
울렸는지를 뽑아냅니다.

## 결과 형식

곡 하나가 이렇게 저장됩니다.

```json
{
  "id": "-gDI19p8oq0",
  "title": "Gran Turismo 5 \"Mesmerium\" Part 1 Chords",
  "url": "https://www.youtube.com/watch?v=-gDI19p8oq0",
  "status": "ok",
  "ocr_rate": 1.0,
  "duration_sec": 58.75,
  "band": { "top": 0.5596, "h": 0.0555, "how": "auto(5/5)" },
  "progression": [
    { "chord": "D 9sus4",     "at": 0.0,  "dur": 2.75 },
    { "chord": "Bb min9(13)", "at": 2.75, "dur": 1.0  },
    { "chord": "C min9(13)",  "at": 3.75, "dur": 1.25 }
  ],
  "unparsed": []
}
```

| 항목 | 뜻 |
|---|---|
| `chord` | 코드 이름 |
| `at` | 시작 시각(초) |
| `dur` | 지속 시간(초) |
| `status` | `ok` / `failed_no_chords` / `failed_low_ocr` |
| `ocr_rate` | 읽어낸 글자를 코드로 해석한 성공률 |
| `band` | 화면 어느 높이를 잘라 읽었는지 |
| `unparsed` | 해석하지 못한 글자. 비어 있으면 완벽 |

## 결과물

| 파일 | 내용 |
|---|---|
| `out/chords.json` | 정상 판독곡 |
| `out/failed.json` | 판독 실패곡 상세 |
| `out/failed.md` | 실패 목록 표 |

## 실행

```bash
uv run --with pillow --with numpy --with rapidocr-onnxruntime python scripts/collect.py all 8 5
```

인자는 `[곡수] [다운로드 병렬수] [읽기 병렬수]`. `all` 대신 숫자를 넣으면
그 개수만 처리합니다. 같은 명령을 다시 넣으면 끝난 곡은 건너뛰고 이어갑니다.

마지막 인자가 컴퓨터를 얼마나 점유할지를 정합니다.

| 값 | 체감 | 전체 소요 |
|---|---|---|
| 5 | 컴퓨터를 거의 못 씀 | 33시간 |
| 3 | 웹서핑·문서 작업에 지장 없음 | 약 50시간 |
| 2 | 거의 느끼지 못함 | 70시간 이상 |

## 처리 방식

곡마다 이 순서로 처리합니다.

1. 영상을 받습니다 (720p, 화면만)
2. 초당 4장을 캡처합니다
3. **코드 글자가 화면 어디에 있는지 찾습니다** — 영상마다 화면 배치가
   달라, 위치를 고정하면 건반을 글자로 잘못 읽습니다
4. 그 부분만 잘라 글자를 읽습니다
5. 앞 장과 같은 화면은 건너뜁니다
6. 같은 코드가 이어진 구간을 묶어 시작 시각과 길이를 냅니다

## 아직 없는 것

- **보이싱** — 화면 건반에 눌린 음이 주황으로 칠해져 있습니다. 픽셀 색만
  읽으면 정확한 보이싱이 나옵니다. 미구현
- **곡명·아티스트 분리** — 지금은 영상 제목에 섞여 있습니다
- **BPM** — 화면에 없습니다

자세한 경위는 [HANDOVER.md](HANDOVER.md)에 있습니다.
